---
name: hokusai-doctor
description: >-
    Diagnoses Hokusai setup problems — missing API key, outcome opt-in not
    enabled — using the doctor checks embedded in the `hokusai_privacy_status`
    MCP tool. Use when Hokusai is misconfigured or not working, or the user runs
    $hokusai-doctor.
---

Use this skill when the user asks Hokusai to diagnose setup issues.

Call `hokusai_privacy_status` and use the embedded `doctor` checks to explain missing API key or outcome opt-in configuration.
