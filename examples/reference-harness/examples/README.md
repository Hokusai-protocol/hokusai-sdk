# Example Payloads

Fake, safe-to-publish examples of the payloads used in the Hokusai route/contribute loop.

- `task-packet.example.json` is a valid `TaskPacket`.
- `contribution-row.example.json` is a valid `technical_task_router_row/v4` — the canonical row submitted to `POST /api/v1/models/30/contributions`. It carries `inference_log_id` with `overrides` (`[]`: the recommendation was followed), a derived `task_descriptor`, `allowed_models`, `selected_models`, `budget_usd`, and one `stage_executions` entry whose `task_cost` is the harness's `@hokusai/costs` report (tokens per model, priced by the shared engine). `actual_cost_usd` is the contributor-reported total; Hokusai reprices from `task_cost`. It is generated by running the reference flow, so it is exactly what the code emits.

The reference harness test suite validates both with `validateTaskPacket` and `validateContributionRow` from `@hokusai/core`, and asserts they contain no credential-shaped strings.

`contribution-row.example.json` was generated by running the reference harness, not written by hand, so it cannot drift from what the code actually emits.
